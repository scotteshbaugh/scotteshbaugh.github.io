Stroke weight comes from --size-icon-stroke-<size>, applied in screen pixels via vector-effect: non-scaling-stroke. The 16px icon draws a 1.6px stroke, not the 1.33px linear scaling would give — matching Figma at every size.

All five sizes — stroke thickens as Figma specifies, not proportionally

Default size — no size attribute given, falls back to 24

Color is inherited, never set by the icon

Any of the 287 by name — nothing to register first

Decorative vs labelled

Without label the icon is aria-hidden and announced to nobody — correct when something around it already has a name. With label the host takes role="img" and is announced once. Don't label an icon that sits inside a labelled control or next to visible text.

Unknown name — renders nothing, warns in the console
